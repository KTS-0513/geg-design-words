# デザインワード100選

AI に絵を頼むとき、「〇〇風」のひとことで方向が決まります。
アイソメトリック、スイススタイル、家紋風など、ロゴづくりに使えるデザインの言葉を100語集めました。
意味・見た目の特徴・ロゴ向きかどうか・頼み方の例・見本の画像・出典つきです。

**ページ**：https://kts-0513.github.io/geg-design-words/

GEG All Hokkaido デザインコンペ（2026年10月29日）のために、GEG All Hokkaido Leaders が作りました。

## ページでできること

- **頼み方の型**：スタイル（〇〇風）＋何を＋背景・条件
- **組み立てる**：言葉を選ぶと、ロゴを頼む文ができて、そのまま Gemini に貼れます
- **言葉の一覧**：8つの種類（様式・運動／画面のスタイル／技法・画材／立体・構図／ロゴの型／文字・書体／日本の表現／色・光）で絞り込めます
- **うまく頼むコツ**と、**使わない言葉**（実在の作家名・作品名・企業のロゴなど）


## 投票フォームの GAS（設定の方式）

Google スライドに貼った作品から、選択肢に画像の付いた Google フォームを作る GAS の設定のしかたです。Cloud のプロジェクト・API・同意画面・紐づけ・接続の確認の手順と、Code.gs・appsscript.json の全文が入っています。

**ページ**：https://kts-0513.github.io/geg-design-words/vote-form/

## 見本の画像について

見本の画像は、すべて Gemini で作りました（55語は2026年10月25日、足した45語は10月27日）。
頼み方は次の文で、「〇〇風」の言葉だけを変え、毎回新しいチャットで作っています。

> GEG ALL Hokkaido のロゴを作ります。〇〇風で作成してください。正方形で作ってください。Googleの4色は使わないでください。

出る画像は毎回変わります。言葉の雰囲気をつかむための見本です。

## 出典

言葉の定義は、各カードの下に出典（Wikipedia、Tate の Art Term、NN/g、Apple のガイドなど）を載せています。
頼み方のコツは Google の公式資料（Gemini API ドキュメント、Google Developers Blog、Vertex AI のプロンプトガイド、Gemini アプリ ヘルプ）、
作風と著作権の扱いは文化庁「AIと著作権に関する考え方について」（令和6年3月15日）によります。いずれも2026年10月25日に確認しました。

ロゴ向きの ◎○△ は、今回のロゴの条件（正方形・3色まで・小さくしても分かる）に照らした目安で、出典のある評価ではありません。
