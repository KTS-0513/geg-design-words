Google スライド × Apps Script × Google フォーム

スライドから投票フォームを作る GAS の設定

参加者が1つのスライドに1人1枚ずつ作品を貼り、メニューを1回押すと、選択肢に作品の画像が付いた投票フォームができます。このページは、その GAS を動かせる状態にするまでの方式をまとめたものです。

準備にかかる時間：Cloud の準備 約15分・スライドに入れて確かめる 約10分／画面の名前は 2026年10月24日時点

仕組み

スライド作品を貼る

No.1〜No.40 の枠に、作品名・ひとこと・画像を入れる

Apps Scriptスライドを読む

メニュー②で、作品のある枠だけを読み取る

ドライブ画像を置く

作品の画像を「リンクを知っている全員：閲覧者」で置く

フォーム選択肢に画像

Forms API で、投票の選択肢それぞれに画像を付ける

集計（メニュー③）もスライドから押します。1位が同票なら、同票の作品だけで決選投票のフォームをその場で作れます。

なぜ Cloud のプロジェクトが要るのか

GAS のふつうの道具（FormApp）では、選択肢に画像を付けられません。付けられるのは Google Forms API だけです。Forms API は GAS の「高度なサービス」に入っていないので、Google Cloud のプロジェクトを作って GAS に紐づける必要があります。

もう1つの壁は画像の置き場所です。Forms のサーバは、渡した URL の画像を自分で取りに行きます。スライドの中の画像の URL は取りに行けませんでした。そこで、作品の画像をドライブに「リンクを知っている全員：閲覧者」で置き、その URL を渡しています。

本命

選択肢に画像

  • 1つの質問の選択肢に、作品の画像が並ぶ
  • Cloud のプロジェクト・3つの API・同意画面が要る
予備

画像を上に並べる

  • 作品の画像を質問の上に並べ、選択肢は「No.12　作品名」の文字だけ
  • Cloud の準備なしで動く。本命が失敗したときも自動でこの形になる

用意するもの

  • 個人の Google アカウント。学校のアカウントだと、ほかの自治体の先生が共有スライドを開けないことがあります。手順はすべて同じアカウントで進めます
  • 作品を集める Google スライド（そのアカウントのドライブに置く）
  • GAS のファイル2つ：Code.gs と appsscript.json

設定の手順

Cloud 側

Google Cloud コンソール（console.cloud.google.com）で行います。お金はかかりません。支払い情報も求められません。

  1. 1

    プロジェクトを作る

    Forms API を使うための「入れ物」です。

    1. Google Cloud コンソールを個人アカウントで開く（初めてなら利用規約に同意）
    2. 画面上のプロジェクト名 → 新しいプロジェクト
    3. 名前を付けて（例：GEG投票フォーム）作成。組織は「なし」のまま
    4. 画面上で、そのプロジェクトが選ばれていることを確かめる
  2. 2

    API を3つ有効にする

    プロジェクトを紐づけると、GAS が使う API はすべてこのプロジェクトで有効になっている必要があります。

    API とサービス → ライブラリ で、次の3つを検索して 有効にする。

    API何に使うか
    Google Forms API選択肢に画像を付ける
    Google Slides APIスライドを画像にする（集計の画面・予備の形）
    Google Drive API作品の画像をドライブに置き、リンクで見られるようにする

    1つでも足りないと、動かしたときに「GCP プロジェクト … への API（drive）の有効化中に権限が拒否されました」のように出ます。括弧の中の名前の API を有効にしてください。

  3. 3

    同意画面を作る

    GAS が「あなたのフォームを編集してよいか」を聞く画面です。

    1. API とサービス → OAuth 同意画面（「Google Auth Platform」の画面に移ることがあります）→ 開始
    2. アプリ名（例：GEG投票フォーム）とサポートのメールアドレス（自分）
    3. 対象は 外部
    4. 連絡先（自分）→ ポリシーに同意 → 作成
    5. 対象（または テストユーザー）→ ユーザーを追加 → 自分のアドレスを追加 → 保存

    公開の申請はしません。「テスト中」のままで使えます。テストユーザーに入れた人だけが GAS を動かせるので、参加者がメニューを押しても許可の画面で止まります。テスト中の許可は7日ほどで切れることがあります。そのときはもう一度許可するだけです。

  4. 4

    プロジェクト番号を控える

    Cloud の概要 → ダッシュボード（または IAM と管理 → 設定）にある、12桁ほどのプロジェクト番号をコピーします。「プロジェクト ID」（英字の名前）ではない方です。

スライド側

作品を集めるスライドで行います。

  1. 5

    スライドに GAS を入れる

    1. スライドの 拡張機能 → Apps Script
    2. 左の歯車 プロジェクトの設定 →「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェック
    3. エディタに戻り、appsscript.json の中身を下のものに貼り替える
    4. エディタの コード.gs の中身を、下の「Code.gs」に貼り替える → 保存

    GAS はスライドに付いています。スライドを別のフォルダへ動かしても一緒に動きます。スライドを ファイル → コピーを作成 すると GAS ごとコピーされます（Cloud の紐づけはコピーされないので、コピーは「画像を上に並べる形」で動きます）。

  2. 6

    Cloud のプロジェクトを紐づける

    1. Apps Script の プロジェクトの設定 →「Google Cloud Platform（GCP）プロジェクト」→ プロジェクトを変更
    2. 手順4のプロジェクト番号を貼る → プロジェクトを設定
  3. 7

    接続を確かめる

    1. スライドの画面を再読み込みする → 上に「投票フォーム」メニューが出る
    2. 投票フォーム → Forms API の接続を確かめる
    3. 許可の画面：続行 → アカウントを選ぶ →「Google で確認されていません」→ 詳細 → （アプリ名）（安全ではないページ）に移動 → 許可
    4. もう一度 Forms API の接続を確かめる を押す
    5. 「選択肢に画像を付けられました」と出れば成功。画像の URL の書き方3通り（lh3・thumbnail・uc）それぞれに ○ か × が出ます。○ が1つでもあれば使えます
    6. 出てきたリンクでテストフォームを開き、選択肢に画像が付いているか目で見る。見たらテストフォームは消す

    「Google で確認されていません」は、自分で作った GAS では必ず出ます。自分のアカウントで、自分が作ったプロジェクトなら進んで大丈夫です。人から渡された GAS のときは、中身を確かめてから許可してください。

appsscript.json

高度なサービスの Slides API と、GAS が使う権限をここで決めています。Forms API はここには書きません（手順6の紐づけと、UrlFetchApp からの呼び出しで使います）。

appsscript.json
{
  "timeZone": "Asia/Tokyo",
  "exceptionLogging": "STACKDRIVER",
  "runtimeVersion": "V8",
  "dependencies": {
    "enabledAdvancedServices": [
      { "userSymbol": "Slides", "serviceId": "slides", "version": "v1" }
    ]
  },
  "oauthScopes": [
    "https://www.googleapis.com/auth/presentations",
    "https://www.googleapis.com/auth/forms",
    "https://www.googleapis.com/auth/forms.body",
    "https://www.googleapis.com/auth/drive",
    "https://www.googleapis.com/auth/script.external_request",
    "https://www.googleapis.com/auth/script.container.ui"
  ]
}
権限使うところ
presentationsスライドを読む・提出用の枠を作る
forms ・ forms.bodyフォームを作る（FormApp）・選択肢に画像を付ける（Forms API）
drive作品の画像をドライブのフォルダに置き、共有を「リンクを知っている全員：閲覧者」にする
script.external_requestForms API とスライドの画像を UrlFetchApp で呼ぶ
script.container.uiスライドのメニューと、完了・集計のダイアログ

/**
 * 作品スライド → 投票フォーム（GEG All Hokkaido デザインコンペ 2026-10-29 用）
 *
 * 参加者が1つの Google スライドに1人1枚ずつ作品を貼る。メニューを押すと、
 * 全作品が並んだ投票フォーム（Google フォーム）ができて、回答用のリンクが出る。
 *
 * メニュー「投票フォーム」
 *   ① 提出用スライドを用意する … 説明スライド＋ No.1〜No.40 の空きスライドを作る（本番前に1回）
 *   ② 投票フォームを作る       … 作品のある番号だけ読み、フォームを作ってリンクを出す
 *   ③ 集計する                 … いちばん新しいフォームの票を数えて順位を出す。1位が同票なら決選投票へ
 *   Forms API の接続を確かめる … 選択肢に画像を付けられるかを、小さなテストフォームで試す
 *
 * 選択肢の画像は Forms API（REST）で付ける（FormApp には選択肢に画像を付ける命令がない）。
 * Forms は画像を URL から取りに行くので、作品の画像をいったんドライブに置き、
 * 「リンクを知っている全員：閲覧者」にしてから、その URL を渡す（スライドの画像の URL は Forms から開けなかった）。
 * Cloud のプロジェクトが紐づいていない・API がエラーを返したときは、
 * 「スライドの画像を上に並べ、最後に番号で選ぶ」形で作る。どちらでも投票はできる。
 *
 * 入れ方・前日リハの手順は DEPLOY_GUIDE.md、仕様は SPEC.md（同じフォルダ）。
 */

/** 説明スライドと No.1〜No.N の空きスライドを作る。すでにある番号は作らない */
function setupSlots() {
  try {
    const pres = SlidesApp.getActivePresentation();
    const existing = {};
    let hasGuide = false;
    pres.getSlides().forEach(function (slide) {
      const no = parseNo_(textOf_(findShape_(slide, TAG.NO)));
      if (no) existing[no] = true;
      if (findShape_(slide, TAG.GUIDE)) hasGuide = true;
    });

    if (!hasGuide) buildGuideSlide_(pres.insertSlide(0, SlidesApp.PredefinedLayout.BLANK), pres);
    let added = 0;
    for (let no = 1; no <= CONFIG.SLOT_COUNT; no++) {
      if (existing[no]) continue;
      buildSlotSlide_(pres.appendSlide(SlidesApp.PredefinedLayout.BLANK), no);
      added++;
    }

    const message = added === 0 && hasGuide
      ? 'No.1〜No.' + CONFIG.SLOT_COUNT + ' はもうそろっています。'
      : (hasGuide ? '' : '1枚目に説明のスライドを入れました。\n') +
        '提出用のスライドを ' + added + ' 枚足しました（No.1〜No.' + CONFIG.SLOT_COUNT + '）。\n' +
        'もとからある白紙のスライドは、いらなければ消してください。';
    SlidesApp.getUi().alert(message);
    return { success: true, message: message, added: added };
  } catch (e) {
    return fail_('提出用のスライドを作れませんでした', e, true);
  }
}

/** 1枚目の説明スライド */

  style_(head, 26, true);

  const steps = [
    '1. 空いている番号のスライドを1枚えらぶ',

    '　　PC：画像を右クリック →［画像をコピー］→ スライドに貼り付け',
    '　　iPad・スマホ：画像を保存 →［挿入］→［画像］→［アップロード］',

/** 提出用スライド1枚（左に画像の場所、右に作品名とひとこと） */
function buildSlotSlide_(slide, no) {
  const noBox = slide.insertTextBox('No.' + no, 28, 14, 200, 44);
  noBox.setTitle(TAG.NO);
  style_(noBox, 26, true);

  const drop = slide.insertShape(SlidesApp.ShapeType.RECTANGLE, 40, 66, 300, 300);
  drop.setTitle(TAG.DROP);
  drop.getFill().setSolidFill('#F5F5F5');
  drop.getBorder().setWeight(1).setDashStyle(SlidesApp.DashStyle.DASH).getLineFill().setSolidFill('#9E9E9E');
  drop.getText().setText('ここに画像を貼る\n（正方形がおすすめ）');
  style_(drop, 14, false, '#757575');
  drop.getText().getParagraphStyle().setParagraphAlignment(SlidesApp.ParagraphAlignment.CENTER);
  drop.setContentAlignment(SlidesApp.ContentAlignment.MIDDLE);

  style_(slide.insertTextBox('作品名', 370, 62, 310, 26), 13, true, '#424242');
  inputBox_(slide, TAG.TITLE, 370, 90, 310, 56, 22, true);
  style_(slide.insertTextBox('ひとこと（込めた思いを1行で）', 370, 160, 310, 26), 13, true, '#424242');
  inputBox_(slide, TAG.COMMENT, 370, 188, 310, 110, 14, false);
  style_(slide.insertTextBox('名前は書かないでください', 370, 330, 310, 24), 11, false, '#757575');
}

/** 参加者が書き込む枠（白地に細い枠線） */
function inputBox_(slide, tag, left, top, width, height, fontSize, bold) {
  const box = slide.insertShape(SlidesApp.ShapeType.RECTANGLE, left, top, width, height);
  box.setTitle(tag);
  box.getFill().setSolidFill('#FFFFFF');
  box.getBorder().setWeight(1).getLineFill().setSolidFill('#BDBDBD');
  box.setContentAlignment(SlidesApp.ContentAlignment.TOP);
  style_(box, fontSize, bold, '#202124');
  return box;
}

/** メニュー「② 投票フォームを作る」 */
function createVoteForm() {
  const ui = SlidesApp.getUi();
  try {
    const props = PropertiesService.getDocumentProperties();
    if (props.getProperty(PROP.FORM_ID)) {
      const again = ui.alert('投票フォームを作る',
        '前に作ったフォームがあります。新しく作りますか？\n（前のフォームはそのまま残ります。③ の集計は新しい方を数えます）',
        ui.ButtonSet.YES_NO);
      if (again !== ui.Button.YES) return { success: false, message: 'やめました' };
    }

    const pres = SlidesApp.getActivePresentation();
    const read = readSlots_(pres);
    if (read.works.length === 0) {
      const msg = '作品が貼られたスライドがありません。\n（画像のある No. のスライドだけを作品として読みます）';
      ui.alert(msg);
      return { success: false, message: msg };
    }

    const votes = askVotes_(ui, read.works.length);
    if (!votes) return { success: false, message: 'やめました' };

    // 画像を貼ったスライドの「ここに画像を貼る」を消す（集計の画面やスライドの画像に写らないように）
    read.works.forEach(function (w) {
      const drop = findShape_(w.slide, TAG.DROP);
      if (drop) drop.remove();
    });

    const res = makeForm_({
      kind: 'prelim',
      pres: pres,
      works: read.works,
      votes: votes,
      title: CONFIG.FORM_TITLE,
      description: 'GEG All Hokkaido のスタッフロゴを決める投票です。\n' +
        '作品は ' + read.works.length + ' 点。いいと思う作品を ' + votesText_(votes) + ' 選んでください。\n' +
        '作者の名前はのせていません。作品で選んでください。',
    });
    res.noImage = read.noImage;
    showLinkDialog_(res, '投票フォームができました');
    return res;
  } catch (e) {
    return fail_('投票フォームを作れませんでした', e, true);
  }
}

/** 予選の票数を聞く。空のまま OK なら「10作品ごとに1票」の数。やめたら 0 */
function askVotes_(ui, count) {
  const def = defaultVotes_(count);
  const r = ui.prompt('投票フォームを作る',
    '作品は ' + count + ' 点です。1人 ' + def + ' 票にします（' + CONFIG.VOTES_PER + '作品ごとに1票）。\n' +
    '変えるときは数字を入れてください。空のまま OK なら ' + def + ' 票です。\n\n' +
    'OK を押すと1〜2分かかります。終わると画面にリンクが出ます。',
    ui.ButtonSet.OK_CANCEL);
  if (r.getSelectedButton() !== ui.Button.OK) return 0;
  const text = toHalfWidth_(String(r.getResponseText() || '').trim());
  if (!text) return def;
  const n = Number(text);
  if (!(Number.isInteger(n) && n >= 1 && n <= count)) {
    ui.alert('票数は 1〜' + count + ' の数字で入れてください。もう一度メニューから押してください。');
    return 0;
  }
  return n;
}

/** 10作品ごとに1票（作品数÷10 の切り上げ・最低1票） */
function defaultVotes_(count) {
  return Math.max(1, Math.ceil(count / CONFIG.VOTES_PER));
}

/**
 * 提出用スライドを読む。
 * 画像のある番号だけを作品にする。作品名・ひとことだけで画像がない番号は noImage に入れる。
 * 同じ番号が2枚あったら（スライドの複製）、2枚目を「No.12-2」にする。
 * @return {{works: Array<Object>, noImage: string[]}}
 */
function readSlots_(pres) {
  const works = [];
  const noImage = [];
  const seen = {};
  pres.getSlides().forEach(function (slide, index) {
    const no = parseNo_(textOf_(findShape_(slide, TAG.NO)));
    if (!no) return;
    seen[no] = (seen[no] || 0) + 1;
    const key = 'No.' + no + (seen[no] > 1 ? '-' + seen[no] : '');
    const title = oneLine_(textOf_(findShape_(slide, TAG.TITLE)), CONFIG.TITLE_MAX);
    const comment = oneLine_(textOf_(findShape_(slide, TAG.COMMENT)), 200);
    const images = slide.getImages();
    if (images.length === 0) {
      if (title || comment) noImage.push(key);
      return;
    }
    works.push({
      key: key, no: no, order: index, title: title, comment: comment,
      pageId: slide.getObjectId(), slide: slide,
    });
  });
  works.sort(function (a, b) { return a.no - b.no || a.order - b.order; });
  return { works: works, noImage: noImage };
}

/**
 * フォームを作り、選択肢に画像を付け、記録してリンクを返す。
 * 選択肢に画像が付けば、それで終わり（スライドを画像にする手間を省く）。
 * 付かなければ、スライドの画像をフォームの上に並べる形にする。
 * @param {{kind:string, pres:Object, works:Object[], votes:number, title:string, description:string}} opts
 * @return {Object} ダイアログにそのまま渡せる結果（Form などのオブジェクトは入れない）
 */
function makeForm_(opts) {
  const built = buildForm_(opts);
  const form = built.form;

  let mode = 'list';
  let modeNote = '選択肢に画像は付けず、画像を上に並べる形にしました（設定で止めています）。';
  let thumbFailed = [];
  const r = CONFIG.USE_CHOICE_IMAGES ? attachWithDrive_(opts, form.getId(), built.voteTitle) : null;
  if (r && r.ok) {
    mode = 'choice';
    modeNote = '選択肢に画像を付けました（' + r.source + ' 形式の URL）。';
  } else {
    thumbFailed = addImageList_(form, opts);
    if (r) modeNote = '選択肢に画像を付けられなかったので、画像を上に並べる形にしました。投票はこのまま使えます。\n理由：' + explainApiError_(r);
  }
  publish_(form);

  const id = form.getId();
  const props = PropertiesService.getDocumentProperties();
  const record = {};
  record[PROP.FORM_ID] = id;
  record[PROP.KIND] = opts.kind;
  record[PROP.VOTE_TITLE] = built.voteTitle;
  record[PROP.WORKS] = JSON.stringify(opts.works.map(storedWork_));
  props.setProperties(record);

  const url = form.getPublishedUrl();
  return {
    success: true,
    message: 'フォームを作りました',
    kind: opts.kind,
    formId: id,
    responderUrl: url,
    shortUrl: shortUrl_(form, url),
    editUrl: form.getEditUrl(),
    count: opts.works.length,
    votes: opts.votes,
    mode: mode,
    modeNote: modeNote,
    thumbFailed: thumbFailed,
  };
}

/** FormApp でフォームの骨組みを作る（投票の質問・理由・満足度。画像はまだ入れない） */
function buildForm_(opts) {
  const form = FormApp.create(opts.title);
  form.setDescription(opts.description)
    .setConfirmationMessage('投票ありがとうございました！ 結果は画面で発表します。')
    .setShowLinkToRespondAgain(false)
    .setAllowResponseEdits(false)
    .setLimitOneResponsePerUser(CONFIG.ONE_RESPONSE_PER_USER);

  const voteTitle = opts.votes === 1 ? '投票（1つ選んでください）' : '投票（' + opts.votes + 'つまで選べます）';
  const values = opts.works.map(labelShort_);
  if (opts.votes === 1) {
    form.addMultipleChoiceItem().setTitle(voteTitle).setChoiceValues(values).setRequired(true);
  } else {
    const validation = FormApp.createCheckboxValidation()
      .setHelpText(opts.votes + 'つまで選べます')
      .requireSelectAtMost(opts.votes)
      .build();
    form.addCheckboxItem().setTitle(voteTitle).setChoiceValues(values).setValidation(validation).setRequired(true);
  }
  if (CONFIG.ASK_REASON) form.addParagraphTextItem().setTitle('選んだ理由（書かなくても大丈夫です）');
  if (opts.kind === 'prelim' && CONFIG.ASK_SATISFACTION) {
    form.addScaleItem().setTitle('今日の会の満足度').setBounds(1, 5).setLabels('いまひとつ', 'とても良い');
  }
  return { form: form, voteTitle: voteTitle };
}

/**
 * 選択肢に画像を付けられなかったときの形：スライドの画像を、投票の質問より上に並べる。
 * @return {string[]} スライドの画像が取れなかった作品
 */
function addImageList_(form, opts) {
  const presId = opts.pres.getId();
  opts.pres.saveAndClose();   // スライドの書き換え（「ここに画像を貼る」を消したこと）を確定させてから画像にする
  const thumbFailed = [];
  const added = [];
  opts.works.forEach(function (w) {
    let thumb = null;
    try {
      thumb = fetchThumbnail_(presId, w.pageId);
    } catch (e) {
      Logger.log('スライドの画像が取れない ' + w.key + ': ' + e.message);
      thumbFailed.push(w.key);
    }
    added.push(thumb
      ? form.addImageItem().setTitle(labelShort_(w)).setHelpText(w.comment || '').setImage(thumb.blob).setWidth(600)
      : form.addSectionHeaderItem().setTitle(labelShort_(w))
        .setHelpText((w.comment ? w.comment + '\n' : '') + '（画像を取り込めませんでした。スライドで見てください）'));
  });
  added.forEach(function (item, i) { form.moveItem(item, i); });
  return thumbFailed;
}

/** 回答を受け付ける状態にする（2026年からの「公開」の仕組みがあれば公開する） */

  } catch (e) {
    Logger.log('setPublished: ' + e.message);
  }
  form.setAcceptingResponses(true);
}

/** 短いリンク。作れない・形が怪しいときは空 */

    return /^https?:\/\//.test(s) ? s : '';
  } catch (e) {
    Logger.log('shortenFormUrl: ' + e.message);
    return '';
  }
}

/**
 * 作品の画像をドライブに置いて、選択肢に付ける。
 * Forms API が使えない（Cloud の準備がない）ときは、ドライブに置く前にやめる。
 * @return {{ok:boolean, source?:string, code?:number, message?:string}}
 */
function attachWithDrive_(opts, formId, voteTitle) {
  const got = formsApi_('get', FORMS_API + formId, ScriptApp.getOAuthToken());
  if (!got.ok) return got;
  const placed = uploadImages_(opts.pres, opts.works);
  if (placed === 0) return { ok: false, code: 0, message: '作品の画像をドライブに置けませんでした' };
  Utilities.sleep(2000);   // 「リンクを知っている全員」が効くまで少し待つ
  return attachChoiceImages_(formId, voteTitle, opts.works, IMAGE_URLS, got.body);
}

/**
 * 各作品のいちばん大きい画像を、ドライブのフォルダに置いて「リンクを知っている全員：閲覧者」にする。
 * 置いたファイルの ID を w.fileId に入れる。会が終わったらフォルダごと消してよい。
 * @return {number} 置けた枚数
 */
function uploadImages_(pres, works) {
  const folder = imageFolder_();
  let placed = 0;
  works.forEach(function (w) {
    try {
      const slide = w.slide || pres.getSlideById(w.pageId);
      const img = slide ? largestImage_(slide.getImages()) : null;
      if (!img) return;
      const file = folder.createFile(img.getBlob().setName(w.key));
      file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
      w.fileId = file.getId();
      placed++;
    } catch (e) {
      Logger.log('ドライブに置けない ' + w.key + ': ' + e.message);
    }
  });
  return placed;
}

/** 選択肢の画像を置くフォルダ（なければ作る） */
function imageFolder_() {
  const it = DriveApp.getFoldersByName(CONFIG.IMAGE_FOLDER);
  return it.hasNext() ? it.next() : DriveApp.createFolder(CONFIG.IMAGE_FOLDER);
}

/**
 * 投票の質問の選択肢に、ドライブに置いた作品の画像を付ける。
 * URL の書き方（formats）を上から順に試し、Forms が受け取れたところで終わる。
 * 選択肢の文字は「No.12　作品名｜ひとこと」にする（上に画像を並べないので、ひとことをここに移す）。
 * @param {Array<{name:string, url:function(string):string}>} formats
 * @param {Object=} formBody Forms API で読んだフォーム（なければここで読む）
 * @return {{ok:boolean, source?:string, code?:number, message?:string}}
 */
function attachChoiceImages_(formId, voteTitle, works, formats, formBody) {
  const token = ScriptApp.getOAuthToken();
  let body = formBody;
  if (!body) {
    const got = formsApi_('get', FORMS_API + formId, token);
    if (!got.ok) return got;
    body = got.body;
  }

  let index = -1;
  let item = null;
  (body.items || []).forEach(function (it, i) {
    if (it.title === voteTitle && it.questionItem) { index = i; item = it; }
  });
  if (!item) return { ok: false, code: 0, message: '投票の質問が見つかりません' };

  // 選択肢と作品は先頭の「No.12」で結びつける。Forms が選択肢の文字の空白などを
  // 置き換えて返すことがあり、文字全体の一致では結びつかなかった（2026-10-24 本番の確認で発生）
  const byKey = {};
  works.forEach(function (w) { byKey[w.key] = w; });
  const sourceOptions = item.questionItem.question.choiceQuestion.options || [];
  const matched = sourceOptions.filter(function (o) { const w = byKey[keyOf_(o.value)]; return w && w.fileId; }).length;
  if (matched === 0) {
    return {
      ok: false, code: 0,
      message: '選択肢と作品を結びつけられませんでした（Forms から返った選択肢：' +
        sourceOptions.slice(0, 3).map(function (o) { return JSON.stringify(o.value); }).join(' / ') + '）',
    };
  }

  let last = null;
  for (let a = 0; a < formats.length; a++) {
    const options = sourceOptions.map(function (o) {
      const w = byKey[keyOf_(o.value)];
      const opt = { value: w ? labelLong_(w) : o.value };
      if (w && w.fileId) opt.image = { sourceUri: formats[a].url(w.fileId), altText: opt.value };
      return opt;
    });
    const newItem = JSON.parse(JSON.stringify(item));
    newItem.questionItem.question.choiceQuestion.options = options;
    const res = formsApi_('post', FORMS_API + formId + ':batchUpdate', token, {
      requests: [{
        updateItem: {
          item: newItem,
          location: { index: index },
          updateMask: 'questionItem.question.choiceQuestion.options',
        },
      }],
    });
    if (res.ok) return { ok: true, source: formats[a].name };
    last = res;
    Logger.log('選択肢の画像（' + formats[a].name + ' 形式）: ' + res.code + ' ' + res.message);
    if (res.code === 401 || res.code === 403 || res.code === 404) break;   // 設定の問題。書き方を変えても同じ
  }
  return last;
}

/** Forms API を呼ぶ。失敗も戻り値で返す */
function formsApi_(method, url, token, payload) {
  const params = {
    method: method,
    headers: { Authorization: 'Bearer ' + token },
    muteHttpExceptions: true,
  };
  if (payload) {
    params.contentType = 'application/json';
    params.payload = JSON.stringify(payload);
  }
  try {
    const r = UrlFetchApp.fetch(url, params);
    const code = r.getResponseCode();
    let body = {};
    try { body = JSON.parse(r.getContentText() || '{}'); } catch (e) { body = {}; }
    const ok = code >= 200 && code < 300;
    return { ok: ok, code: code, body: body, message: ok ? '' : ((body.error && body.error.message) || ('HTTP ' + code)) };
  } catch (e) {
    return { ok: false, code: 0, body: {}, message: e.message };
  }
}

/** Forms API の失敗を、直し方の分かる言葉にする */
function explainApiError_(r) {
  const m = String((r && r.message) || '');
  if (/has not been used|is disabled|SERVICE_DISABLED/i.test(m)) {
    return 'Forms API が有効になっていないか、Cloud のプロジェクトが紐づいていない（DEPLOY_GUIDE の Step 2・4）。' + m;
  }
  if (r && r.code === 403 && /insufficient|scope/i.test(m)) {
    return '許可の範囲が足りない（appsscript.json を貼り直して、もう一度許可する）。' + m;
  }
  if (r && r.code === 400 && /fetch image/i.test(m)) {
    return 'Forms のサーバが、その URL から画像を取りに行けなかった。' + m;
  }
  if (r && r.code === 400) return 'Forms が画像の URL を受け取れなかった。' + m;
  return (r && r.code ? 'HTTP ' + r.code + '：' : '') + m;
}

/** スライド1枚の画像の URL（PNG・30分有効）。混んでいる（429）ときは待ってやり直す */
function thumbnailUrl_(presId, pageId) {
  return withRetry_(function () {
    return Slides.Presentations.Pages.getThumbnail(presId, pageId, {
      'thumbnailProperties.thumbnailSize': CONFIG.THUMB_SIZE,
      'thumbnailProperties.mimeType': 'PNG',
    });
  }).contentUrl;
}

/** スライド1枚の画像（URL と、フォームに入れる画像そのもの） */
function fetchThumbnail_(presId, pageId) {
  const url = thumbnailUrl_(presId, pageId);
  return { url: url, blob: fetchBlob_(url) };
}

/** 画像を取る。そのままで断られたら、自分の許可を付けてもう一度 */
function fetchBlob_(url) {
  let r = UrlFetchApp.fetch(url, { muteHttpExceptions: true });
  if (r.getResponseCode() !== 200) {
    r = UrlFetchApp.fetch(url, {
      headers: { Authorization: 'Bearer ' + ScriptApp.getOAuthToken() },
      muteHttpExceptions: true,
    });
  }
  if (r.getResponseCode() !== 200) throw new Error('画像を取れませんでした（HTTP ' + r.getResponseCode() + '）');
  return r.getBlob().setName('slide.png');
}

/** 割り当て超え（1分60回）のときだけ、1・2・4・8秒と待ってやり直す */
function withRetry_(fn) {
  for (let i = 0; ; i++) {
    try {
      return fn();
    } catch (e) {
      if (i >= 4 || !/429|quota|rate limit|RESOURCE_EXHAUSTED/i.test(e.message)) throw e;
      Utilities.sleep(1000 * Math.pow(2, i));
    }
  }
}

/** スライドに貼られた画像のうち、いちばん大きいもの（＝作品）。なければ null */
function largestImage_(images) {
  let best = null;
  images.forEach(function (img) {
    if (!best || img.getWidth() * img.getHeight() > best.getWidth() * best.getHeight()) best = img;
  });
  return best;
}

/**
 * いちばん新しいフォームの票を数える。
 * 選択肢の文字の先頭「No.12」（重複なら「No.12-2」）で作品を見分ける。
 * @return {{success:boolean, message:string, kind?:string, responses?:number,
 *           ranking?:Array<{key:string,no:number,title:string,votes:number}>, tied?:string[], winner?:string}}
 */
function tally_() {
  const props = PropertiesService.getDocumentProperties();
  const formId = props.getProperty(PROP.FORM_ID);
  if (!formId) return { success: false, message: 'まだ投票フォームを作っていません（先に ② を押してください）。' };
  const voteTitle = props.getProperty(PROP.VOTE_TITLE);
  const works = JSON.parse(props.getProperty(PROP.WORKS) || '[]');
  const kind = props.getProperty(PROP.KIND) || 'prelim';

  const counts = {};
  works.forEach(function (w) { counts[w.key] = 0; });
  const responses = FormApp.openById(formId).getResponses();
  responses.forEach(function (r) {
    r.getItemResponses().forEach(function (ir) {
      if (ir.getItem().getTitle() !== voteTitle) return;
      const ans = ir.getResponse();
      (Array.isArray(ans) ? ans : [ans]).forEach(function (v) {
        const key = keyOf_(v);
        if (key && Object.prototype.hasOwnProperty.call(counts, key)) counts[key]++;
      });
    });
  });

  const ranking = works.map(function (w) {
    return { key: w.key, no: w.no, title: w.title, votes: counts[w.key], pageId: w.pageId };
  }).sort(function (a, b) { return b.votes - a.votes || a.no - b.no || (a.key < b.key ? -1 : 1); });

  const top = ranking.length ? ranking[0].votes : 0;
  if (top === 0) {
    return { success: false, message: 'まだ票が入っていません（回答 ' + responses.length + ' 件）。' };
  }
  const leaders = ranking.filter(function (r) { return r.votes === top; }).map(function (r) { return r.key; });
  return {
    success: true,
    message: '集計しました',
    kind: kind,
    responses: responses.length,
    ranking: ranking,
    tied: leaders.length > 1 ? leaders : [],
    winner: leaders.length === 1 ? leaders[0] : '',
  };
}

    const message = (okAny
      ? '選択肢に画像を付けられました。'
      : '選択肢に画像を付けられませんでした（本番は画像を上に並べる形で動きます）。') +
      '\n\n' + lines.join('\n') +
      (okAny ? '\n\nテストフォームを開いて、選択肢に画像が付いているか見てください：\n' + form.getEditUrl() : '') +
      '\n\nこの文を全文そのまま送ってください。見たら、マイドライブの「【テスト】Forms API の確認」は消してください。';
    ui.alert(message);
    return { success: okAny, message: message, editUrl: form.getEditUrl() };
  } catch (e) {
    return fail_('確かめられませんでした', e, true);
  }
}

/** リンクの部分（予選・決選で共通）。ダイアログの外からも使えるよう文字列で返す */
function linkBlock_(res, heading) {
  const parts = [];
  parts.push('<h2>' + esc_(heading) + '</h2>');
  parts.push('<p class="note">作品 ' + res.count + ' 点・1人 ' + res.votes + ' 票</p>');
  parts.push('<p class="label">回答用のリンク（Meet のチャットに貼る）</p>');
  parts.push('<div class="url"><input id="u0" value="' + esc_(res.responderUrl) + '" readonly>' +
    '<button onclick="copyUrl(\'u0\', this)">コピー</button></div>');
  if (res.shortUrl) {
    parts.push('<p class="label">短いリンク（前日リハで開けるか確かめたものだけ使う）</p>');
    parts.push('<div class="url"><input id="u1" value="' + esc_(res.shortUrl) + '" readonly>' +
      '<button class="sub" onclick="copyUrl(\'u1\', this)">コピー</button></div>');
  }
  parts.push('<p class="' + (res.mode === 'choice' ? 'note' : 'warn') + '">' + esc_(res.modeNote).replace(/\n/g, '<br>') + '</p>');
  if (res.thumbFailed && res.thumbFailed.length) {
    parts.push('<p class="warn">画像を取り込めなかった作品：' + esc_(res.thumbFailed.join('・')) + '（名前だけ入っています）</p>');
  }
  if (res.noImage && res.noImage.length) {
    parts.push('<p class="warn">作品名だけで画像がない番号：' + esc_(res.noImage.join('・')) + '（フォームに入れていません）</p>');
  }
  parts.push('<p class="note"><a href="' + esc_(res.editUrl) + '" target="_blank">編集画面でフォームを開く</a></p>');
  return parts.join('\n');
}

/** 集計のダイアログ（1位を大きく。同票なら決選投票のボタン） */
function showTallyDialog_(t) {
  const presId = SlidesApp.getActivePresentation().getId();
  const byKey = {};
  t.ranking.forEach(function (r) { byKey[r.key] = r; });
  const featured = t.winner ? [t.winner] : t.tied.slice(0, 4);

  parts.push('<h2>' + (t.kind === 'runoff' ? '決選投票の結果' : '投票の結果') + '（回答 ' + t.responses + ' 件）</h2>');

    parts.push('<p class="big">1位　' + esc_(labelShort_(w)) + '　' + w.votes + ' 票</p>');
  } else {
    parts.push('<p class="big warn">1位が同票です：' + esc_(t.tied.join('・')) + '（' + byKey[t.tied[0]].votes + ' 票ずつ）</p>');
  }
  if (!t.winner) {
    parts.push('<div class="row" id="runoff"><button onclick="makeRunoff(this)">決選投票フォームを作る（' + t.tied.length + ' 作品・1人1票）</button></div>');
  }
  parts.push('<div class="imgs">');
  featured.forEach(function (key) {
    let src = '';
    try { src = thumbnailUrl_(presId, byKey[key].pageId); } catch (e) { src = ''; }
    parts.push('<figure class="' + (t.winner ? 'one' : 'many') + '">' + (src ? '<img src="' + esc_(src) + '" alt="' + esc_(key) + '">' : '') +
      '<figcaption>' + esc_(labelShort_(byKey[key])) + '</figcaption></figure>');
  });
  parts.push('</div>');
  parts.push('<table><tr><th>順位</th><th>作品</th><th>票</th></tr>');
  let rank = 0;
  let prev = null;
  t.ranking.forEach(function (r, i) {
    if (r.votes !== prev) { rank = i + 1; prev = r.votes; }
    parts.push('<tr><td>' + rank + '</td><td>' + esc_(labelShort_(r)) + '</td><td>' + r.votes + '</td></tr>');
  });
  parts.push('</table>');
  parts.push('<div class="row"><button class="sub" onclick="google.script.host.close()">閉じる</button></div>');

  const script = '<script>var TIED = ' + JSON.stringify(t.tied) + ';</script>';
  const html = dialogPage_(parts.join('\n') + script);
  SlidesApp.getUi().showModalDialog(HtmlService.createHtmlOutput(html).setWidth(900).setHeight(640), '集計');
}

/** 目印（代替テキストのタイトル）で図形を探す */
function findShape_(slide, tag) {
  const shapes = slide.getShapes();
  for (let i = 0; i < shapes.length; i++) {

  }

/** 図形の文字（前後の空白と最後の改行を除く）。図形がなければ空 */
function textOf_(shape) {
  return shape ? String(shape.getText().asString() || '').trim() : '';
}

/** 「No.12」→ 12。読めなければ 0 */
function parseNo_(text) {
  const m = String(text || '').match(/No\.?\s*(\d+)/i);
  return m ? Number(m[1]) : 0;
}

/** 選択肢の文字の先頭から作品の目印（"No.12" か "No.12-2"）を取り出す */
function keyOf_(value) {
  const m = String(value || '').match(/^(No\.\d+(?:-\d+)?)/);
  return m ? m[1] : '';
}

/** 「No.12　作品名」（作品名がなければ「（作品名なし）」） */
function labelShort_(w) {
  return w.key + '　' + (w.title || '（作品名なし）');
}

/** 「No.12　作品名｜ひとこと」（選択肢に画像を付けるとき用） */
function labelLong_(w) {
  const c = oneLine_(w.comment, CONFIG.COMMENT_MAX);
  return labelShort_(w) + (c ? '｜' + c : '');
}

/** 改行をつなげて1行にし、長ければ切る */
function oneLine_(text, max) {
  const s = String(text || '').replace(/\s*\n\s*/g, ' ').trim();
  return s.length > max ? s.slice(0, max - 1) + '…' : s;
}

/** 全角の数字を半角に */
function toHalfWidth_(text) {
  return text.replace(/[０-９]/g, function (c) { return String.fromCharCode(c.charCodeAt(0) - 0xFEE0); });
}

/** 「1つ」「3つまで」 */
function votesText_(votes) {
  return votes === 1 ? '1つ' : votes + 'つまで';
}

/** 記録に残す作品の情報（スライドそのものは残せないので外す） */
function storedWork_(w) {
  return { key: w.key, no: w.no, title: w.title, comment: oneLine_(w.comment, CONFIG.COMMENT_MAX), pageId: w.pageId };
}

/** 文字に書式をつける（空の枠では効かないことがあるが、止めずに進む） */
function style_(shape, size, bold, color) {
  try {
    const ts = shape.getText().getTextStyle().setFontSize(size).setBold(!!bold);
    if (color) ts.setForegroundColor(color);
  } catch (e) {
    Logger.log('書式: ' + e.message);
  }
  return shape;
}

/** HTML に入れる文字をエスケープする（参加者が書いた作品名も入るので必ず通す） */
function esc_(s) {
  return String(s == null ? '' : s)
    .replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;').replace(/'/g, '&#39;');
}

/**
 * 紐づけた Cloud のプロジェクトで API が有効になっていないときの直し方。
 * 例：「GCP プロジェクト 123 への API（drive）の有効化中に権限が拒否されました」（2026-10-24 本物で発生）
 */
function apiHint_(message) {
  const names = { drive: 'Google Drive API', slides: 'Google Slides API', forms: 'Google Forms API' };
  const m = String(message || '').match(/API[（(]\s*(\w+)\s*[）)]/) ||
    String(message || '').match(/(drive|slides|forms)\.googleapis\.com/i);
  if (!m || !/有効化|enable|has not been used|disabled/i.test(message)) return '';
  const api = names[m[1].toLowerCase()] || m[1];
  return '\n\n→ Cloud のコンソールの［API とサービス］→［ライブラリ］で「' + api + '」を有効にしてください（DEPLOY_GUIDE の Step 2-1）。';
}

/** 失敗を記録して（必要なら画面にも出して）、失敗の戻り値を返す */
function fail_(label, e, showAlert) {
  const raw = e && e.message ? e.message : String(e);
  const message = label + '\n\n' + raw + apiHint_(raw);
  Logger.log(message + (e && e.stack ? '\n' + e.stack : ''));
  if (showAlert) {
    try { SlidesApp.getUi().alert(message + '\n\nこの文を全文そのまま送ってください。'); } catch (ignore) { /* 画面がない */ }
  }
  return { success: false, message: message };
}

設定のあとの使い方

① 提出用スライドを用意する

説明のスライドと No.1〜No.40 の枠を作ります。会の前に1回だけ。

② 投票フォームを作る

作品のあるスライドだけを読んでフォームを作ります。票数は作品10点ごとに1票（23点なら3票）で、その場で変えられます。1〜2分待つと回答用のリンクが出ます。

③ 集計する

順位をダイアログに大きく出します。1位が同票なら「決選投票フォームを作る」ボタンが出ます（同票の作品だけ・1人1票）。

GAS を動かすのはスライドの持ち主だけです。参加者は貼る・投票するだけで、GAS にはさわりません。

止まったとき

  • ドライブにできたフォルダ「デザインコンペ_投票用画像」を消す（作品の画像がリンクで見られる状態で置いてあります）
  • 接続の確認で作ったテストフォーム「【テスト】Forms API の確認」を消す
